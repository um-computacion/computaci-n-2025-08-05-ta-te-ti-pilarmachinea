# Ta-te-ti
Este proyecto es una implementación del juego de Ta-te-ti en Python.

El codigo fuente está en el directorio `src`, y los tests en el directorio `tests`.

## Descripción del juego
El juego consiste en dos jugadores, uno de los cuales gana si pueden completar una fila de 3 casillas con una ficha X. El juego termina cuando uno de los jugadores gana, empata o se acaban los turnos.
